# 当前进度与未完成事项 — 2026-09-08

## 本轮已实现的代码

- 桌面导航默认 72px 图标栏，可展开为 240px；子菜单在栏内展开，不覆盖正文。手机保留抽屉，切换到桌面宽度会释放滚动锁。
- 邮箱登录、创建账号、验证邮件提示与密码恢复入口。新学生邮箱映射为 Student，学校教师邮箱映射为 Teacher；不会自动获得社团管理权限。
- 管理员修改 Advisor 身份时必须选择 Club；支持一个人管理多个社团，保留最后一个管理员保护。
- 自定义角色支持创建、修改、分配、撤销和删除，权限目录为 `clubs.manage`、`clubs.govern`、`site.manage`，可限制到单个社团。
- 网站介绍编辑器支持首页、About、Support、Footer 四段文字。
- 董事会/Advisor 提交学校公告，管理员审核通过后发布；拒绝带原因，重复审核不会重复发布。
- 身份变更、自定义权限与网站文字有数据库审计；管理员审计页每类显示最新 100 条，社团管理页保留本社团历史。
- 社团内容、会议添加、董事会任命、公告、照片、合规信息等表单增加保存/失败提示。工作人员可发布或归档社团，数据库阻止普通内容编辑者直接修改发布状态。
- 私有社团聊天继续使用原有成员权限和 Realtime；修正超过上限时只显示最早消息的问题。
- 认证网络短暂故障不再主动清空登录 Cookie；增加相应单元测试。
- 上传前检查 4 MB 限制，Next.js 请求上限为 4.25 MiB；公共图片许可提示、Privacy/Terms 和帮助入口已加入。
- 移除管理员页面无实际数据支撑的报告摘要，查询失败不显示虚假的零。
